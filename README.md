# DevSnippet

DevSnippet è una piccola applicazione Flutter pensata per salvare, visualizzare e modificare snippet di codice personali. Ogni snippet viene associato all'utente autenticato e sincronizzato con Firebase.

## Tecnologie usate

- Flutter
- Provider
- Firebase Auth
- Firestore

## Come avviarla

1. Installa le dipendenze:

```bash
flutter pub get
```

1. Avvia l'app:

```bash
flutter run
```
